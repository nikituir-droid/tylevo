# TYLEVELO

A feature-rich Roblox executor script with a modern, customizable UI.

> **Warning:** Use at your own risk. Exploiting in Roblox violates the Roblox Terms of Use and may result in account bans.

---

## Features

- **Aimbot** — smooth high-quality aiming with adjustable FOV ring, bone selection, wall-check and custom keybind
- **ESP**
  - Criminal ESP — see and highlight targets
  - Police ESP — see and highlight wanted civilians, star level display
  - Faction colors with click-to-cycle palette
  - Distance limit, names, health, stars
- **Farm**
  - Diamond Farm
  - Job Farm — automatic route, adjustable flight speed, box counter HUD
- **Themes** — accent color presets, custom HEX input, smooth RGB rainbow mode
- **Anti AFK**
- **Switch Server** — teleport back to the game
- **Reset Cheat** — full clean unload
- User avatar displayed in the menu header and sidebar
- Menu toggle: `K`

## Usage

1. Use a Roblox injector/executor (e.g. Xeno).
2. Copy the contents of `Tylevelo.lua` into the executor.
3. Execute. Press `K` to open/close the menu.
